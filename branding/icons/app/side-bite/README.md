# Side Bite App Assets

This folder contains committed desktop packaging exports derived from [side_bite.svg](/Users/nomionz/dev/clawbro/clawbrowser_core/clawbrowser/resources/side_bite.svg).

Files:

- `app.icns`: macOS app bundle icon
- `product_logo_*.png`: Linux and packaging overlay icon sizes
- `generate_assets.sh`: regenerate the committed exports from the source SVG

Run `./generate_assets.sh` from this folder after updating the source SVG.
